## Installation

- Clone both [this](https://github.com/dnaHunter/dts-frontend) and the [backend repository](https://github.com/dnaHunter/dts-api) onto your own systems. Follow the read me on the backend for how to run it.

- Run `npm i` to install dependencies and node modules.

- Make sure you have the backend server running.

- Add the url the backend is running on to the .env file.

- Use `npm run dev` to run the client server.
